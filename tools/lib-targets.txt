# Куда вендорится lib/get_cloud_user.sh.

# Каталог `lib/` соседним до гостя НЕ доезжает: единственный механизм доставки —
# `COPY_IN <каталог одного расширения>:/opt/vmsetup/`, а потребители ищут файл
# рядом с собой (`$SCRIPT_DIR/get_cloud_user.sh`). Поэтому источник истины один,
# а копии рядом со скриптами генерируются `tools/sync-lib.sh` и сверяются
# `tools/check-lib.sh`.
#
# Формат: <путь каталога расширения от корня репозитория>
# Пустые строки и строки, начинающиеся с `#`, игнорируются.
