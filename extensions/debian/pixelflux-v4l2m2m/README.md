# pixelflux-v4l2m2m

Аппаратное кодирование H.264 в Selkies на платах, чей кодер выставлен
стандартным **V4L2 M2M**: Raspberry Pi 3/4 и CM4 (`bcm2835-codec`), а тем же
интерфейсом — RK356x и i.MX8M.

С **Selkies 2.0.0** кодирование даёт сам базовый образ: релиз несёт
`pixelflux 2.1.0` с бэкендом `v4l2m2m`, и лестница кодеров сама падает с
VA-API (которого на Малине нет) на M2M. Подменять и патчить больше нечего —
расширение свелось к **проверке**.

## Что даёт

Замер на Raspberry Pi 4, живой рабочий стол 1080p, одна сессия, разница только
в `use_cpu`:

| | кадров | процессор |
|---|---|---|
| Железо (`v4l2m2m`) | 10.1 fps | **0.378 ядра** |
| Софт (x264) | 12.2 fps | **1.128 ядра** |

Втрое меньше процессора. Частота при этом у софта чуть выше: x264 раскладывается
на четыре ядра, а аппаратный движок кодирует по кадру за раз. Расширение продаёт
ядра, не частоту.

## Порядок в VMFILE

```
EXTENSION selkies ...
EXTENSION pixelflux-v4l2m2m
```

После `selkies`: проверяется модуль внутри того AppImage, который тот ставит.
`install.sh` требует, чтобы `selkies` шёл раньше.

## Что проверяется

**На сборке** — что базовый `pixelflux` действительно несёт бэкенд `v4l2m2m`
(если апстрим уронит его при следующем подъёме Selkies, сборка встанет, а не
уедет тихо в софт), и что модуль импортируется.

**На первой загрузке** — служба `verify-pixelflux-v4l2m2m`: спрашивает у
pixelflux, объявлен ли `v4l2m2m` для h264, и **громко отказывает**, если нет.
Журнал сессии для этого не годится: строка `Encoder: …` появляется только при
подключённом клиенте, а у соседнего расширения такая строка однажды соврала.

## Чего расширение не делает

**Не ставит и не подменяет колесо.** Бэкенд уже в базовом Selkies; роль
расширения — проверка, а не установка.

**Не ставится на платы без кодера.** На Pi 5 его нет в кремнии вовсе — там
расширение в цепочке указывать нельзя, и проверка первой загрузки это уронит.

**Не подкладывает libxcb и не собирает шим gbm.** Это болезни L4T, которые
лечит `pixelflux-tegra`; на Малине AppImage работает со своими библиотеками.

## Когда исчезнет совсем

Если Selkies когда-нибудь сам начнёт громко отказывать при откате в софт на
плате, от которой ждут железа, расширение станет не нужно. Пока такой проверки
у него нет — её и делает это расширение.
